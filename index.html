07 Frequently asked

Before requesting access.

Are the tools commercially released?

No. Publishing Manager V2.4 and Clash Manager V2.6 are presented as private beta products while supported-version testing and commercial-readiness work continue. Control Center remains in development.

Which Revit versions are supported?

The current product build scope covers Autodesk Revit 2021, 2022, 2023, 2024, 2025 and 2026 on Microsoft Windows.

Does the licence system upload project models?

No. The current licensing workflow does not upload Revit models, project geometry, drawings, drawing registers or clash reports.

Can the products be licensed separately?

The account can define product scope. Publishing Manager and Clash Manager also update independently, while using the same My Account experience.

Do the tools replace final BIM checking?

No. They assist publishing and coordination. Users remain responsible for engineering judgement, project standards, authority requirements and final deliverable checking.
